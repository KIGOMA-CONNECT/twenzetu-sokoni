# Chapter 4 — Core Values

Our values are behavioural. A value is not something we claim in a document; it is something we can observe in a commit, a pull request review, a decision, or a support reply.

| Value | Kiswahili | What it means in practice |
|---|---|---|
| **Trust** | Uaminifu | We protect money, data, and reputation. Security is not a feature request — it is our default posture. We keep our promises. |
| **Unity** | Umoja | One platform, one constitution, one team. We build suites that compose, not silos that fragment. We succeed together with our vendors, partners, and users. |
| **Craftsmanship** | Ubunifu | We engineer to global standards. Code is reviewed, tested, documented, and observable. Quality is the cheapest thing we build when done early. |
| **Accountability** | Uwajibikaji | We own outcomes, not just tasks. When something breaks, we fix the cause, learn, and write it down. We ship what we own. |
| **Service** | Ukarimu | The user comes first — from a vendor in a rural district to a partner integrating our API. Hospitality is a business model. |
| **Simplicity** | Usahili | We solve problems with the smallest responsible solution. We fight complexity because complexity is where trust dies. |
| **Courage** | Ujasiri | We tell the truth in reviews and decisions. We make hard calls. We ship early and learn — Africa cannot wait for perfect. |

## How values are applied

1. **In review:** "Does this change uphold *Trust* and *Craftsmanship*?" is a legitimate review objection.
2. **In architecture:** a proposal that fights *Simplicity* and *Unity* must justify itself before the council (Chapter 8).
3. **In product:** a feature that damages *Service* or *Trust* is not added just because it is profitable.
4. **In conflict:** when two principles collide, we resolve them in the Decision Framework (Chapter 9), not by personality.

## Anti-values

We explicitly reject:

- hero culture (single points of failure praised as "rock stars"),
- "move fast and break things" applied to money or user data,
- undocumented decisions ("it just works" is not an explanation),
- proprietary lock-in as a strategy.
